📊 Ex-ante vs Ex-post प्रत्याशित vs यथार्थ

1 Ex-ante vs Ex-post
Ex-ante = Planned (योजना / अनुमान)
Ex-post = Actual (वास्तविक / घटित)
📋 Ex-ante (Planned / अनुमान)

मान लो तुमने सोचा:

₹5000 खर्च करूँगा ₹2000 बचाऊँगा

👉 यह Plan है।

⬇️
📌 Ex-post (Actual / वास्तविक)

लेकिन महीने के अंत में वास्तव में:

₹4500 खर्च हुए ₹2500 बच गए

👉 यह Reality है।

📊 अंतर:
Ex-ante (Plan) ₹5000 खर्च + ₹2000 बचत
Ex-post (Actual) ₹4500 खर्च + ₹2500 बचत
अंतर: खर्च में ₹500 कम, बचत में ₹500 ज़्यादा

🚀 Trick

Ex-ante = Plan
⬇️
Ex-post = Actual

"Ex-ante = Plan (पहले सोचा)
Ex-post = Reality (बाद में हुआ)"
